# imzeeshan

A responsive static technical blog, using Pod Talk's mint (#00CC99), blue (#0066CC), and pale blue (#F0F8FF) palette. Original layout and CSS; no framework or build step needed.

## Preview
Open index.html in your browser. All navigation uses relative paths.

## Publish on GitHub Pages
Upload the contents of this folder to a GitHub repository. In Settings → Pages, select Deploy from a branch, your default branch, and /(root). Save and use the URL GitHub provides.

## Customize
- Replace imzeeshan with your blog name in the HTML files.
- Edit about.html with your biography.
- The two sample posts are github-pages.html and rag-explained.html.
- Duplicate an article page to add a post, then add its card to index.html and blogs.html.
- Adjust colors in style.css.

The sample site intentionally uses no analytics, remote images, contact forms, or live view counts. Everything runs from static files. Reading times are sample editorial estimates.
